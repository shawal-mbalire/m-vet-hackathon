# M-Vet Hackathon

Machine learning solutions for animal type detection and body scoring, developed during the M-Vet Hackathon 2024.

## Contents

- `animalType-79.ipynb` - Animal type classification (79% accuracy)
- `animalType79.88.ipynb` - Improved animal type detection (79.88% accuracy)
- `bodyScore-62.ipynb` - Body condition scoring (62% accuracy)

## Tech Stack

- **Language**: Python
- **Framework**: YOLO (Ultralytics)
- **Libraries**: PyTorch, pandas, scikit-learn, W&B, OpenCV
- **Platform**: Jupyter Notebook

## Setup

```bash
pip install ultralytics wandb pandas scikit-learn opencv-python
```

## Usage

Open notebooks in Jupyter:
```bash
jupyter notebook animalType-79.ipynb
```
